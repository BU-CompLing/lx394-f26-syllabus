# Natural Language Processing with Python

**Analyzing Text with the Natural Language Toolkit**<br />
**Steven Bird, Ewan Klein, and Edward Loper**

In this course, we will be using the first six chapters of the textbook [_Natural Language Processing with Python_](https://www.nltk.org/book/) by Steven Bird, Ewan Klein, and Edward Loper. The portion of the textbook we are using in class is available here. The rest of the textbook is available on the [NLTK website](https://www.nltk.org/book/).
